# Luke's world of work

A browser-based story world built from Luke Hayes' work and education history.

Live: https://auraofintelligence.github.io/Lukes-world-of-work-experience/

The first publication is a generated concept holding page. The interactive world follows in the next release. Work and education are the initial scope; startups and volunteering are deferred.

## Local preview

Run `python -m http.server 4173` in this directory, then open http://localhost:4173.

GitHub Actions publishes the static files on each push to `main`.
